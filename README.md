# Italiano flashcards

Flashcards and lesson notes for a beginners' Italian course, in one app.

- **Study** with spaced repetition: rate each card Again / Hard / Good / Easy and it comes back when it's due.
- **Test** yourself with multiple choice.
- **Progress**: streak, mastered cards, reviews per day and how much you remember.
- **Notes** for each lesson.

Open the site once with internet and it saves itself to the device. After that it works offline. On a phone, use "Add to Home Screen". Progress is saved in the browser on each device.
