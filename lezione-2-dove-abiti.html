Lesson notes

Saying where you live

Informal (tu)Formal (Lei)
NameCome ti chiami?Come si chiama?
SpellingCome si scrive?Come si scrive?
TownDove abiti?Dove abita?
Exactly whereDove di preciso?Dove di preciso?
  • Towns take a, not in: Abito a Oxford, Abito a Londra. Countries take in: Abito in Inghilterra.
  • Big place first, then the detail: town, then street.
  • The formal “you” uses the same form as “he/she”: Lei abita.

Abitare (to live)

PersonItalianEnglishEnding
ioabitoI live-o
tuabitiyou live (informal)-i
lui / lei / Leiabitahe / she lives; you live (formal)-a
noiabitiamowe live-iamo
voiabitateyou all live-ate
loroabitanothey live-ano
  • The underlined vowel carries the stress. It jumps forward for noi and voi, then back to the start for loro.
  • Italian usually drops io, tu, noi. The ending tells you who, so get that last letter right.
  • Every regular -are verb uses the same endings: parlo, parli, parla, parliamo, parlate, parlano.
  • For this lesson, focus on the first three (abito, abiti, abita). Those are the ones you use in conversation.
